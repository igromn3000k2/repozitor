Информация об иконке файла

Если после регистрации `.cpr` файлов в системе ваш файл выглядит как стандартный ретро-значок окна/системной иконки из библиотеки moricons.dll — это полностью нормально и означает, что ассоциация прошла успешно!

Отображение оригинальной иконки подтверждает, что реестр Windows правильно связал расширение .cpr с типом Cpuprogram Script File и интерпретатором int000.hta.

Синтаксис и правила языка

  • • Одиночные скобки { — префикс { указывается строго в начале управляющих строк и тегов. Закрывать её скобкой } не нужно.
  • • Блок версии — ограничивается тегами {<ver> и {<ver/> (или {</ver>). Внутри него прописывается версия языка.
  • • Комментарии — все символы после знака ; игнорируются при выполнении.
  • • Спец-символы `#` и `$` — служат завершающими маркерами команд и автоматически отсекаются интерпретатором.

Основные команды

  • {IF1: — устанавливает внутренний флаг выполнения в состояние 1.
  • {IF0: — сбрасывает внутренний флаг выполнения в состояние 0.
  • TEXT="Сообщение"$ — выводит указанный текст в консоль интерпретатора.
  • BEEP="Частота, Задержка, Длительность"$# — воспроизводит звуковой сигнал заданный частоты через системный динамик.
  • {CLOSEPRGRMIF0## — завершает работу программы, если флаг равен 0.
  • JMPTO имя_метки / имя_метки: — переход к указанной метке в коде.

Пример кода (.cpr)

{
{1.0 ; Версия нашего языка
{
{IF1: ; Запускаем флаг
TEXT="Hello world"$
BEEP="500,20,1"$# ; Звуковой сигнал
{CLOSEPRGRMIF0##
